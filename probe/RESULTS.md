# 探针实测结果

刺激集：200 items × 10 条件 = 2000 条，`--n-items 200 --seed 0`。

## 主表：umT5-XXL（Wan 2.1 / 2.2 实际使用的编码器）

`layer_24`（末层），mean-pooled，padding 已 mask。

| 条件 | d_cond | SNS | p (vs filler) | 编辑距离 |
|---|---|---|---|---|
| `atelic` | 0.0815 | **0.36** | 1.5e-34 | 0.206 |
| `prospective` | 0.1288 | **0.58** | 2.8e-28 | 0.256 |
| `perf` | 0.1765 | **0.80** | 1.8e-14 | 0.206 |
| `result` | 0.1975 | **0.90** | 5.1e-06 | 0.206 |
| `failed` | 0.2847 | 1.30 | 3.5e-29 | 0.472 |
| *`filler`（锚点）* | 0.2249 | 1.00 | — | 0.310 |
| *`paraphrase_min`（同义替换）* | 0.0764 | 0.34 | 1.5e-34 | 0.103 |
| *`paraphrase`（语序变化）* | 0.1680 | 0.76 | 1.0e-26 | 0.868 |
| *`other_verb`（换事件）* | 0.1123 | 0.49 | 3.9e-31 | 0.103 |

**mean SNS = 0.79，4/5 个体貌条件低于 1.0。**

> 改变"事件是否达成"对条件向量的影响，小于往句尾追加四个语义无关的词。

### 意外收获：编辑距离完全匹配的语义标尺

`paraphrase_min` 与 `other_verb` 的编辑距离**同为 0.103**（都只改一个 token），
因此二者的差值是**纯语义**的，不含表层成分：

```
同义替换（无语义变化）      0.34
换动词（完全不同的事件）    0.49
```

以此为尺重读体貌条件：`atelic` 仅 0.36，改动的 token 数是上述两者的**两倍**，
移动量却低于 `other_verb`、几乎等同于同义替换。
**这个三方对比是论文的主图。**

### 对照：t5-base（通用 T5，非视频模型编码器）

|---|---|
| `atelic` | 0.43 |
| `prospective` | 0.56 |
| `result` | 0.85 |
| `perf` | 0.86 |
| `failed` | 1.86 |

mean SNS = 0.91，同样 4/5 低于 1.0。**两个编码器结论一致，且 umT5 更极端。**

## token 级复算：主结论存活，但主张须收窄

`analyze_tokens.py`，同一 `filler` 锚点，因此与池化 SNS 直接可比。

| 条件 | chamfer | SNS_tok | maxNov | SNS_nov | SNS_pooled | shift |
|---|---|---|---|---|---|---|
| `atelic` | 0.1584 | **0.51** | 0.5499 | **0.66** | 0.36 | +0.15 |
| `prospective` | 0.2367 | **0.77** | 0.7082 | 0.86 | 0.58 | +0.19 |
| `perf` | 0.2707 | 0.89 | 0.6449 | 0.78 | 0.80 | +0.08 |
| `result` | 0.2876 | 0.95 | 0.6848 | 0.84 | 0.90 | +0.05 |
| `failed` | 0.3767 | 1.24 | 0.8266 | 1.01 | 1.30 | −0.06 |
| *`paraphrase_min`* | 0.1419 | 0.45 | 0.5822 | 0.70 | 0.34 | +0.11 |
| *`paraphrase`* | 0.2963 | 0.97 | 0.6987 | 0.85 | 0.76 | +0.21 |
| *`other_verb`* | 0.2064 | 0.66 | 0.6604 | 0.80 | 0.49 | +0.17 |

**mean SNS_tok = 0.87，仍 4/5 低于锚点 → 池化结论不是测量假象。**

### 三处必须如实报告的细节

**1. 指标被压缩，不是体貌变显著了。** 除 `failed` 外全部条件（含对照）上移：
池化动态范围 0.34–1.30，token 级 0.45–1.24。token 级测量的分辨率更低。

**2. 语义标尺在两个层级都成立**，且 token 级更宽：

| | pooled | token |
|---|---|---|
| `paraphrase_min`（无语义变化） | 0.34 | 0.45 |
| `other_verb`（换事件） | 0.49 | 0.66 |
| **`atelic`** | **0.36** | **0.51** |

`atelic` 在两个层级都低于 `other_verb`，而其编辑距离是后者的两倍（0.206 vs 0.103）。
**全表最硬的一格，主图建在这里。**

**3. 「4/5 低于锚点」实际由 `atelic`(0.51) 与 `prospective`(0.77) 撑起。**
`perf`(0.89) 与 `result`(0.95) 已贴近 1.0——`result` 虽 p=6e-05 显著，
幅度仅差 5%。**论文不能笼统说"体貌普遍不显著"，必须分格陈述。**

### 主张必须收窄（重要）

`maxNov` 是变体中**最与众不同的单个 token**，正是 cross-attention 能专门选中的东西：

- `prospective` 0.86 **高于** `other_verb` 0.80
- `result` 0.84 ≈ `paraphrase` 0.85
- `failed` 1.01 ≈ 锚点

即：**作为单个 token，体貌标记的独特性与换掉整个动词是同一量级。**

因此准确的主张只能是：

> 体貌标记在条件表示中**存在且可被注意力选中**；
> 它对**整体条件**的扰动幅度低于语义无关的填充词。

**不能**主张"生成器看不见它"。看得见与否只有生成实验能回答——
这把生成实验从"验证"抬为**唯一能定论的一步**。

## v2（三轴刺激集，196 items × 15 条件）：主结果确立

### 直接最小对立对 —— **论文的主数字**

`d(A, B)` 直接测两个条件之间的距离，地板是 `d(prog, paraphrase_min)`（无语义变化的改写）。
这一步必要：两个条件可以都贴近参照句的噪声底，却仍然彼此相距很远。

| 最小对立对 | d_pair | floor | ratio | p |
|---|---|---|---|---|
| **`atelic` vs `telic_plural`**（终结性，只差一个 `the`） | 0.0699 | 0.0713 | **0.98** | **0.475（不显著）** |
| `prog` vs `prospective`（事件是否发生） | 0.1179 | 0.0713 | 1.65 | 3.2e-25 |
| `perf` vs `result`（完成体 vs 结果态，差一个 `has`） | 0.1231 | 0.0713 | 1.73 | 7.1e-27 |
| `phase_begin` vs `phase_finish`（起始 vs 终结） | 0.1540 | 0.0713 | 2.16 | 1.5e-30 |

> **`slicing apples` 与 `slicing the apples` 之间的距离，
> 与"把 `in` 换成 `inside`"在统计上无法区分。**

**该零结果具有说服力**：同一批数据、同样的 n=196，其余三个对立均以 p < 1e-24 被检出。
检验力充分，测不出差异即为真实的无差异——这是为零结果辩护的正确方式。

### 三轴 SNS（池化，umT5-XXL）

| 轴 | 均值 | 低于锚点 | 备注 |
|---|---|---|---|
| **终结性** | **0.35** | 2/2 | `atelic` 0.34、`telic_plural` 0.36，与 `paraphrase_min` 0.32 同级 |
| 体貌 | 0.88 | 3/4 | `prospective` 0.54 最低；`failed` 1.33（编辑距离最高，含表层成分） |
| 相位动词 | 0.88 | 3/4 | `phase_begin` **1.02，p=0.40 与 filler 无差异** |

**相位动词轴是必需的反例。** 它证明该指标并非对所有语法变化都给低分——
加一个 `began`（1 token）移动的距离等于加四个废话词，
而换掉整个动词（`other_verb`，同为 1 token）只有 0.45。
审稿人必问"你的指标是不是对什么都不敏感"，这一轴就是回答。

### token 级复算（v2）

mean SNS_tok = 0.81，**9/10 低于锚点**，判定 POOLED RESULT SURVIVES。
`atelic` 0.48、`telic_plural` 0.52 仍为全表最低。

### 浮现的概括

```
显性词汇材料（began / tried…failed / has）  →  区分良好，远高于地板
功能性标记（限定词、数）                    →  与无意义改写无统计差异
```

> **编码器对承载语义的实词敏感，对由限定词与数承载的区别失明。**

这比"模型忽略体貌"精确，且可证伪。论文应以**终结性为主发现**，
体貌为次要（分格陈述），相位动词为反例。

## v3（五条终结性条件，196 × 18）：**推翻 v2 的"终结性是主发现"**

加入同终结性内部对照后，v2 的解读站不住了。

### 关键比较（改动类型匹配：两者都只改一个纯功能词）

| 对立 | 终结性 | ratio | p |
|---|---|---|---|
| `atelic` vs `telic_plural`（bare → the） | **改变** | 0.98 | 0.53 |
| `atelic` vs `atelic_some`（bare → some） | **不变** | 1.02 | 0.995 |

**两者相同，都在地板上，都不显著。**
编码器对"翻转终结性的限定词替换"与"不翻转的限定词替换"一视同仁。

### 真正的解释变量：被改动词汇的实义含量

| 对立 | 改动的词 | ratio |
|---|---|---|
| bare ↔ the | 纯功能词 | 0.98 |
| bare ↔ some | 纯功能词 | 1.02 |
| the ↔ three | 数词，有实义 | 1.20 |
| bare ↔ three | 数词，有实义 | 1.16 |
| `perf` ↔ `result`（has） | 助动词 | 1.73 |
| `prog` ↔ `prospective`（about to） | 实词短语 | 1.66 |
| `phase_begin` ↔ `phase_finish` | 实词 | 2.17 |

```
实词（has / began / tried…failed）      →  1.66 – 2.17
数词（three，有实义）                    →  1.16 – 1.20
纯功能词（the / some / 光杆）            →  0.98 – 1.02（地板）
```

### 修正后的结论

> **编码器的表示位移与"被改动词汇的实义含量"成正比，
> 与"该改动造成的语义后果"无关。**

**"模型不表征终结性"这一主张不成立** —— 数据不支持，因为编码器对所有限定词
一律迟钝，终结性并未被特殊对待。修正后的结论更宽、更难反驳。

> ⚠️ 本文件上方 v2 一节写有"终结性为主发现"，**已被本节推翻**，保留备查。
> 这正是加入同终结性对照的价值：没有它会得出一个过强且可被一句话推翻的主张。

### 对论文结构的影响（净改善）

编码器分析由"辅助小节"升级为**给生成实验下可证伪预测**：

| 区别由什么承载 | 编码器 | 对生成的预测 |
|---|---|---|
| 纯功能词（`apples` / `the apples`） | 分辨不出 | **生成必然无法区分**——信息上无依据。若视频有差异，是测量出了问题 |
| 实词（`has` / `began` / `tried…failed`） | 分辨良好 | 生成**可以**区分。若仍不区分，**这才是论文的发现** |

→ 有意思的格子是**体貌与相位动词**（编码器有信号、生成器可能不用）；
终结性组降为**信息论下界的对照**。

## 逐层定位：**null result**

25 层的探针准确率几乎全是 1.000（最低 0.992），**从 layer_0 起就是平线**。

- 信息从嵌入层就存在，贯穿整个编码器，**没有"在哪一层丢失"可定位**
- 原计划中"机制定位"作为相对 OSCBench 的额外贡献，**不成立，应从论文规划中删除**

## 线性探针：接近平凡，只能作对照

| 分组 | 准确率 | 置换基线 | bag-of-words |
|---|---|---|---|
| 留出动词 | 0.995 | 0.153 | 0.956 |
| 留出物体 | 0.997 | 0.195 | 0.914 |

layer_0 即达 1.000，说明探针实质上只在检测 `has` / `tried` / `about to`
这些 token 是否存在——T5 系编码器本就保留 token 身份。

**结论：(b) 探针与 (c) 逐层是平凡结果，作为对照报告即可，不能当作发现。
论文的证据必须全部落在 (a) 几何上。**

## 对论文规划的影响

| 项 | 变化 |
|---|---|
| 核心主张「信息存在但幅度低」 | **在真实编码器上确证**，且比通用 T5 更极端 |
| 「机制定位：信息在哪一层丢失」 | **删除**——逐层平线，无处可定位 |
| 免训练差向量干预 | **从加分项升为必需**。方向存在、线性可解码、贯穿各层，注入是良定义的；且这是唯一能给出因果证据的实验 |
| 编码器瓶颈叙事 | **排除**。信息完整到达生成器 |

## 必须写进 Limitations

1. **池化是近似**。扩散模型经 cross-attention 消费**整个 token 序列**，
   本分析用的是 mean-pooled 向量。`--save-tokens` 可保留逐 token 状态重做。
2. **`failed` 的 1.30 有表层成分**。它的编辑距离 0.472 为全表最高，
   多出的 token 本身就买到距离。**主证据应放在 `atelic` 与 `prospective` 上**——
   它们编辑距离与其他体貌条件相同（0.206 / 0.256），SNS 却最低。
3. **几何幅度 ≠ 生成行为**。"0.79 个 filler 的距离"不等于"生成器会忽略它"，
   后者需要生成实验与差向量干预来验证。

## 复现

```bash
python build_stimuli.py --n-items 200 --seed 0

# 池化层级
python encode.py --model google/umt5-xxl --dtype bfloat16 --layers all --out emb.npz
python analyze.py --emb emb.npz --all-layers --out result.json

# token 层级（效度检验）
python encode.py --model google/umt5-xxl --dtype bfloat16 --save-tokens --out emb_tok.npz
python analyze_tokens.py --emb emb_tok.npz --pooled-result result.json --out result_tok.json
```
