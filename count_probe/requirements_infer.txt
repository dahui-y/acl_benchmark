# CountGen 推理 + 评测的最小依赖集。
#
# 与 help_code/make-it-count/requirements.txt 的差别，逐条有据：
#
# 1. transformers：原文件写的是
#      git+https://github.com/huggingface/transformers.git@dbc12269ed5546b2da9236b9f1078b95b6a4d3d5
#    这条与同一文件里的 spacy-transformers==1.2.5（要求 transformers<4.31.0）冲突，
#    而且国内大概率拉不动。取那个 commit 的 src/transformers/__init__.py 看，
#      __version__ = "4.29.0.dev0"
#    所以钉 4.29.2（最接近的正式版），同时满足
#      spacy-transformers <4.31 ✓   diffusers 0.25 的 >=4.25.1 ✓   tokenizers 0.13.3 的 <0.14 ✓
#
# 2. 删掉推理用不到的：clip / taming-transformers* / kornia / pytorch-lightning /
#    wandb / tensorboard / plotly / lit / cmake / nvidia-*。
#    依据：扫了 pipeline/ utils/ dataset/ evaluation_script.py 的全部 import，
#    它们只出现在 train_relayout/（我们不训练）或根本没被 import。
#
# 3. torch/torchvision 不写在这里 —— 要按 CUDA 选轮子，见 ENV.md。
#
# 用法： pip install -r count_probe/requirements_infer.txt

# ★ setuptools 不是可选的：accelerate 0.18.0 在 utils/torch_xla.py 里
#   `import pkg_resources`，而那是 setuptools 提供的。conda-forge 的 python
#   现在默认不往环境里装 setuptools，而我们全用 wheel 装（wheel 运行时不需要它），
#   于是 `import diffusers` 会在 transformers→accelerate 这条链上炸
#   `ModuleNotFoundError: No module named 'pkg_resources'`。
#   钉 <81：setuptools 81 起把 pkg_resources 标为弃用并计划移除（最新已 84.x）。
setuptools<81

#   参数解析改动 typer 0.7 没适配。症状：`python -m spacy download` 拼出
#   `.../download/-en_core_web_trf/-en_core_web_trf.tar.gz#egg===en_core_web_trf`
#   （模型名成了空串）。更要命的是 spacy/__init__.py 里有
