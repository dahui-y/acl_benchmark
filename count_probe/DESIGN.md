# DESIGN —— 检测修正器（方向 c）· 预登记（2026-08-21）

本文档在跑任何 GPU 实验**之前**写死设计、标定预算与生死判据。依据全部来自
FINDINGS.md 与 Phase 0/B 的一手读数。**改判据必须在本文件留痕并说明理由。**

## 1. 方法（纯删除原型，Phase C = correct_batch.py）

vanilla SDXL 生成 → YOLOv8x 数目标类 → 多出 k 个则删分数最低的 k 个框
（并列取小面积）→ 框膨胀 24px 成 mask → base SDXL 遮罩重去噪
（diffusers SDXLInpaintPipeline，4 通道 UNet 逐步 latent 混合 = RePaint 式）
→ 像素级贴回（mask 外原像素，羽化 8px）→ 重检测，仍多则再来一轮（≤2 轮）。

零训练部件、零新权重、零 LLM、无梯度图。与两位在位者的机制区别：
CountGen 靠注意力梯度引导（已证伪：评测集净 0，迭代空转）；
SLD 靠 GPT-4 控制器 + GLIGEN 训练权重 + 自修自评（OWLv2 修 OWLv2 评）。

## 2. 立项依据（全部一手，出处见 FINDINGS.md）

- 换算率之门（见数前定 80%）：**P(v9e=N | v8x=N) = 85.7%**（n=70，vanilla）。
  ⚠️ 第一次门检误用了边缘一致率（66.5%）并宣判死亡 —— 修正环只在"宣布够数"
  时需要评测器点头。两次判定的阈值都在见数前预登记。
- 头寸（v8x 视角，167 题）：不动 70 / 要删 70 / 要补 27。删除主导。
- 盈亏平衡：不动题贡献 ≈60，要补题 ≈+3，故
  **打平 CountGen(95 题)：p_del × t_edit ≥ 0.46；+10 分(112 题)：≥ 0.70**
  （p_del = 环内删除成功率；t_edit = 编辑图上的评测器确认率，≤85.7%）。
- 改坏通道上限：v9e 对而 v8x 错的 7 题会被误编辑，预期损失 1~2 题。

## 3. 标定预算（超出即调参违纪）

新调参集 tune2（60 题，seed=20260821，排除评测集 + 旧调参集）上，只许比：

    strength ∈ {0.8, 1.0} × prompt-mode ∈ {ctx, bg}   —— 共 4 个配置

其余旋钮（dilate=24 / feather=8 / steps=40 / guidance=5.0 / rounds=2 /
删除选择规则 / conf=检测器默认）**全部定死，不扫**。选定配置后评测集只跑一次。
旧调参集（tune.json，已评 16 配置）不得再用于任何选择。

## 4. 生死判据（原型级，tune2 上）

记 tune2 上"v8x 说要删"的题集 D：

- **活**：最优配置在 D 上环内删除成功率 p_del ≥ 0.6，且整批相对同批 CountGen
  的配对 McNemar 方向为正；画质红线（相对 CountGen 逐张配对：colourfulness
  中位 ≈0、无色张数不升、CLIPScore 均值不降超过 0.3）不破。
  → 进入评测集（一次），并再议补缺失操作。
- **死**：四个配置的 p_del 全部 < 0.5，或画质红线全破。
  → **方向 c 终结，不再有第三种机制**（复活牌已用过一次且有据；再翻案即自欺），
  转诊断/评测协议论文。
- 中间地带：p_del ∈ [0.5, 0.6) → 只允许分析失败案例并写明原因，不允许扫新旋钮；
  若失败集中于可命名的单一机制（如洞里重新长出目标类），允许**一个**针对性
  修改再测一轮，须先在本文件登记。

## 5. 评测协议（防循环性，三重）

1. 主口径：YOLOv9e（基准惯例），与 CountGen 同一评测链、配对 McNemar。
2. 第三方：OWLv2 对两臂同测（绝对值噪，两臂差值有意义）。
3. 作者盲数：主对比子集上盲法人工计数（计数是客观量；披露作者自评 + 盲法 +
   n + 检验方法）。环内 v8x 与评测器 v9e 的家族重叠必须在文中披露。

## 6. 已知风险（现在写下，免得事后装惊讶）

- t_edit 未知：85.7% 在天生干净的 vanilla 上量得，编辑图只会更低。
- 洞里复生：重去噪可能重新长出目标类（negative_prompt=类名是唯一防线）。
- 密集粘连场景框重叠：删一个框的 mask 可能吃掉邻近实例的一部分。
- v8x 与 v9e 对"删干净了没有"的分歧直接吃掉收益（换算率的编辑图版本）。
- N>9 档按基准惯例不计分；tune2 已剔除。
