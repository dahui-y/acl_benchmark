## 0. 为什么要重写这份表述

先前的表述是：「我们读了 CountGen 的代码，发现 `loss_utils.py:5` 把布局
二值化了」。这在审稿人眼里是**给一个系统打补丁**，不是研究。

对照 CountGen 自己怎么立题（论文 §1）：
1. **能力缺口**：文生图控制不了数量，有实际用途。
2. **为什么难 —— 一个表征层面的问题**：计数需要 *objectness*（在一堆相似
   实体中把某一个当作独立个体），而**「扩散模型是否具备这种表征」当时未知**；
   加上文本控制不了全局空间布局。
3. **方法是该分析的直接后果**：先探测表征是否存在（逐层逐时刻 PCA → `l^up_52`），
   有了就用它数数、改布局、引导生成。

它的动机是一个**关于表征的问题**，方法是那个问题的答案，代码细节在附录。
我们的内容必须放在同一层次上表述。

## 1. 研究问题

> **计数控制的瓶颈不在空间定位，而在实例个体化（individuation）：
> 如何让生成过程表达「这里恰好是一个独立个体」，而不只是「这里有目标类的东西」。**

支撑这个断言的一手测量（评测集 167 题，`blob_split.py`）：

- 布局阶段几乎无误：ReLayout 把区域数改对 **97/98**。
- 而最终数对只有 **41.8%**。
- 误差的精确摊派（恒等式 `yolo − k = 裂开 − 空着 + 越界`）：
  **越界 ≈ 0**（465 个区域、约 500 个框，只有 1 个框落在布局之外）。

**越界为零是枢纽**：空间控制已经做到位了，「物体只出现在指定位置」这件事
在位者解决了。**剩下的全部误差都不是空间误差**，而是「一块区域里到底算几个
个体」的误差 —— 裂开（一区多物）与合并（两区并一物，表现为空区）。

一句话：**空间约束与实例数之间没有一一对应。数量不是位置的函数。**

## 2. 研究动机

1. **这种表征已被证明存在。** CountGen 的核心发现就是 `l^up_52` 的自注意力
   **携带实例身份**（论文 Fig. 2 的 PCA：同类不同实例呈不同颜色）。它把
   「扩散模型是否表征 objectness」这个当时未知的问题回答成「是」。
2. **但这个表征只被用来「读」，没被用来「写」。** 它用该表征**数**实例；
   而反过来施加的控制信号是纯空间的前景/背景二值图。**读的时候认实例，
   写的时候不认。**
3. **我们量到的误差恰好全部落在「写」没表达的那一维上**（见 §1）。
   论文 §7 Limitations 第一句自承其中一个形态：
   *"results in multiple instances of an object in an area intended for just one"*
   —— 症状作者看到了，成因是控制信号里没有「个体」这个概念。
4. **缺口不止于 CountGen。** 整条 layout-to-image 线（BoundedAttention、
   GLIGEN、Reason-Out-Your-Layout 等）传递的都是「哪里有物体」的空间信号，
   同一个缺口都在。

文献位置：**对象中心学习（slot attention 一线）用训练出来的 slot 做个体化；
CountGen 证明预训练扩散模型内部已有这种表征；我们把它从「可读取」变成
「可写入」—— 训练自由的个体化控制。**

## 3. 方法（是上述分析的直接后果）

把「恰好 k 个个体」表达在模型自己的实例身份表征上：

- **软**：`up_52` 的亲和矩阵上，同一个体内部亲和高、不同个体之间亲和低
  —— 即「让 DBSCAN 恰好读出 k 个簇」的可微版本。治**裂开**。
- **硬**：不同个体之间不许互相聚合特征。治**合并**。

零训练、零新权重、零 LLM。实现细节与判据见 DESIGN2.md。

## 4. ★ 可证伪的几何预言（写死于检验之前）

好的动机必须生出**新的**预言。若下列预言不成立，§1–§2 的表述就是给数据编
故事，**必须推翻重来**，不得改口。

对立假说 H0：「这些误差只是检测器噪声」。两个假说在几何上给出相反预言：

| 观测量 | 个体化假说 | H0（检测器噪声） |
|---|---|---|
| **P1** 裂开 vs 区域面积 | **随面积单调上升** | 无预言（漏检不会凭空多出框） |
| **P2** 空着 vs 与最近邻区距离 | **距离越小越容易空**（并成一个） | 无预言 |
| **P3** 空着 vs 区域面积 | 无强预言 | **小面积更容易空**（小目标漏检） |

**P4（最强版本，可选）**：一个区域里的物体数 ≈ 区域面积 / 该类的典型物体面积
—— 即模型按**密度**填充区域，而非按**个数**。若成立，「空间布局控制不了数量」
就从观察升格为**机制**。

### 判读规则（见数前定死）

- **必须控制 N 分层**：N 越大区域越小越拥挤，面积与距离都与 N 混杂。
  P1/P2/P3 一律在 N 分层内计算，并报合并后的分层统计量。
- **统计量**：Spearman 秩相关 + 置换检验 p 值（置换 20000 次），
  与本项目其它检验同源，不引入新工具。
- **P1 是主判据**：Spearman ρ > 0 且置换 p < 0.05 → 个体化表述成立。
  ρ ≤ 0 或不显著 → **§1–§2 作废**，退回「我们发现了三个误差通道」这个
  较弱但诚实的表述，并在论文里只作为诊断报出。
- **P2 为辅**：方向对上则加强，不成立不单独否定（合并的几何刻画比裂开难）。
- **P3 若成立**：同时坐实「空着」通道被漏检污染，这与 FINDINGS §8.7 的
  可信度分层一致，说明摊派表的两个通道确实不等价。
- **P4 为加分项**：不成立不影响 §1–§2。

### 混杂与边界（现在写下）

- 区域面积以 32×32 网格的格数计；距离用两区域最近格的切比雪夫距离。
- 「裂开」「空着」的归属沿用 `blob_split.py` 的两条规则（cover / centroid），
  **两条规则下结论必须一致**，只在一条上成立不算。
- 评测器是 YOLOv9e，它自己会错；P3 正是用来量这个污染的。
- 本检验只用评测集（`cocoount2`），**不碰 tune3**，与方法验证完全隔离。
