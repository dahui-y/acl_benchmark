# 第一步：把校验器先钉死

整条路的地基是一句话：**检测器数出来的整数，可以当真值用。**
这一步就是去证伪它，用的是**别人已经付过钱的标注**——COCO val2017 的实例标注里
本来就有"这张图有几个 X"。**不新增任何标注，不看任何一张我们自己生成的图。**

这一步**只能杀死方向，不能认证方向**。它跑在真实照片上，而我们最终要数的是生成图；
真实照片上过不了，生成图上更过不了，所以它是必要条件，不是充分条件。

---

## 判据（**在看到数字之前写下**）

主判据不是"数得准不准"，是**"N 和 1 分不分得开"**。

因为基准真正做的那个判断是：`each ... a balloon`（蕴含 3）和 `... together`（蕴含 1）
产出的图，数量上能不能区分。一个**有偏但稳定**的检测器——真值 5 它一直报 4——
照样能完美区分 3 和 1，基准活得下去；一个**在真值附近抖**的检测器不行，
哪怕它的平均值好看。所以 `report.py` 把 N-vs-1 的配对排序单独报，
**并把并列判为失败**——并列正是"两个读法分不开"的那种情形。

| 结果 | 判定 | 动作 |
|---|---|---|
| N-vs-1 有序率 ≥ 0.95 **且** κ ≥ 0.70 | 🟢 过 | 进第二步（别名封口）与第三步（pilot） |
| 有序率 0.85–0.95 | 🟡 有条件过 | 只保留逐类筛查通过的物体类与 N 档，**并把筛查表写进论文** |
| 有序率 < 0.85 **或** 加权 κ < 0.60 | 🔴 **不过** | **"检测器当校验器"整条路作废**，切到备选方向②（毫秒/赫兹级声学校验） |

κ ≥ 0.70 这条线的参照是 GenEval 自己报的计数 κ = 0.823（对人工，5 折）。
我们的判据比它松，因为我们的格子被刻意做成了更难的一档：**计数带是均衡的**，
不像原始池子那样 71% 都是 N=1。

---

## 三个脚本

| 文件 | 作用 |
|---|---|
| `cells.py` | 从 COCO 金标注里造格子：(图, 类) → 金标数量 |
| `detect.py` | 跑检测器，**存下每一个框的分数**，不存计数 |
| `report.py` | 阈值扫描、混淆矩阵、分档/分类准确率、N-vs-1 分离度 |

### 格子是怎么造的（两个必须处理的坑）

**crowd 区域。** `iscrowd=1` 是一块盖住"不确定多少个"的连通区。
一张图对某类只有一个 crowd 标注，**不等于"1 个"**。带 crowd 的 (图,类) 直接丢掉。

**背景里的小实例。** COCO 把每一个可见实例都标了，包括几像素的。
而"三个苹果"生成出来的是三个显眼的苹果——检测器在真实照片里漏掉一个 12 像素的苹果，
对我们没有任何预测力。所以只保留**该类的所有实例都大于面积阈值**的图；
有边缘实例的图**丢掉而不是计入**，因为那种图的金标数量本身就可争，
留下它等于在测我们自己的阈值。

这是个刻意做干净的区制。**这种乐观是故意的**——过不了就是真的过不了。

### 为什么存框不存计数

GenEval 明确写了：计数任务要把置信阈值从 0.3 提到 0.9，因为同类多实例会引来
一大片低置信框。我们**存下 0.05 以上的所有框**，把阈值放到 `report.py` 里扫，
这样 0.9 这个数是**在我们自己的物体分布上被重新验证的**，不是照抄的。
（第一批 4 张图就复现了这个现象：一张金标 1 个苹果的图，
检测器给出 0.98 / 0.22 / 0.11 三个框。）

**`STORE_FLOOR` 不要往上调**——调高等于把扫描的下半段悄悄截掉，
让最后胜出的那个阈值显得比实际好。

### 两个检测器，都要标定

| | 用途 |
|---|---|
| `mask2former`（`facebook/mask2former-swin-large-coco-instance`） | **GenEval 用的就是它**，所以我们的数和一个已发表的数可比 |
| `owlv2`（`google/owlv2-base-patch16-ensemble`） | 开放词表。真实题目的物体表不会停在 COCO 的 80 类里 |

两器在**我们自己生成的图上**的一致率，是我们用来顶替"人工核验最终指标"那一格的东西
（真实照片和生成图之间有域偏移，这是明写在 limitation 里的）。所以两个都得先在这里标定。

## 跑法

```bash
pip install torch torchvision transformers pillow

# 1. 金标注（241 MB；只需要 instances_val2017.json）
curl -L -o ann.zip http://images.cocodataset.org/annotations/annotations_trainval2017.zip

# 2. 造格子：N∈{1..5} 每档 90 个，每个 (类,N) 最多 10 个
python cells.py --max-count 5 --per-n 90 --per-class-n 10

# 3. 检测（图片按需单张下载并缓存，不用下整个 6 GB 的 val2017）
python detect.py --detector mask2former
python detect.py --detector owlv2

# 4. 报告
python report.py --pred data/pred_mask2former.jsonl data/pred_owlv2.jsonl
```

`detect.py` 断点续跑，键是 (image_id, class)。

**国内机器**：`images.cocodataset.org` 一般可达；HF 权重走 `HF_ENDPOINT=https://hf-mirror.com`。
这一步没有 GPU 也能跑——实测 CPU 上 mask2former 约 **2.9 s/图**，415 格约 20 分钟。
